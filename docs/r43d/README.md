# docs/r43d — R43-D / Ψ

Изолированное пространство для проекта вокруг уравнения **R43 / R43-D / Ψ**
(тематически не связано с картографическим ядром MainMap; вынесено сюда как
версионируемая «внешняя платформа» для восстановления контекста).

## Точка входа
**[`GLOBAL_CONTEXT.md`](./GLOBAL_CONTEXT.md)** — прочитай его целиком, чтобы
полностью восстановить цели, что доказано расчётами, что невозможно, и план
доработки. Все остальные файлы здесь — исполняемые доказательства к нему.

## Структура
```
docs/r43d/
├── GLOBAL_CONTEXT.md            # главный документ (миссия, верификация, топологии, план)
├── verification/                # скрипты проверки (numpy) — печатают PASS/FAIL
│   ├── r43d_verifier.py             # 9 тестов всех механизмов R43-D
│   ├── check_author_numbers.py      # сверка 4 авторских результатов + тождество маски
│   ├── equation_identity.py         # доказательство A=B=C
│   ├── r43d_dynamics_tests.py       # α-сокращение, контракция, ограниченность
│   ├── r43d_mechanism_tests.py      # OU / Хебб / Пуассон против теории
│   └── verify_psi_t.py              # 6 фактов про уравнение Ψ(t) с производными
└── demos/
    ├── r43d_net_classifier.py       # рабочий классификатор (attention+ρ), acc ≈0.96
    └── R43D_Verifier_Colab.ipynb    # тот же верификатор + графики для Google Colab
```

## Запуск
```bash
python3 docs/r43d/verification/r43d_verifier.py        # numpy
python3 docs/r43d/demos/r43d_net_classifier.py         # numpy + scikit-learn
```
Colab: загрузить `demos/R43D_Verifier_Colab.ipynb` → Выполнить все.
