# R43 O1 — СТРАТЕГИЯ РАЗРАБОТКИ

> **Контекст.** R43 O1 — рабочая разработка под цель «замена дифференциальной
> системы уравнений». Имя выбрано во избежание путаницы с R43 / R43-D / Ψ(t).
> Этот файл — стратегия. Все определения, ограничения и критерии успеха взяты
> **из исходных файлов автора** (см. цитаты) и из доказанного в
> `../GLOBAL_CONTEXT.md`. Подчиняется протоколу поддержки (`../GLOBAL_CONTEXT.md` §13).

---

## 0. Краткая суть (one-liner)
R43 O1 — **дискретный, derivative-free, фазово-связанный динамический оператор**,
который извлекает когерентную структуру из хаотического поля фазовых узлов в
реальном времени и нацелен на нишу, где интегрирование ОДУ ломается
(Piecewise / вложенность / события).

---

## 1. ОТКУДА ВЗЯТА ПОСТАНОВКА (трассировка к источникам)

### 1.1. Предметная область (что моделирует / на чём проверяем) — из файлов
Единственная конкретная фальсифицируемая постановка в исходниках:
- Вход: *«необработанный массив Ψ-узлов — условно 10 000+ структур в ℝ⁴»*.
- Задача: *«выявить устойчиво взаимодействующие узлы»*, *«если cos(ΔΦᵢⱼ)→1 — узлы когерентны»*.
- Эталон автора: *«из 10 000 узлов → выделяется 700, где фазовая корреляция устойчива, ρₙ>θ_гарм»*.
- Принцип: *«не выявлять порядок из хаоса, а выявлять внутреннюю фазовую гармонию хаоса»*.

Прочее («энергопотоки», «нейросети», «FPGA», «Цитадельные ядра») — области
ПРИМЕНЕНИЯ без предметной модели. Физический смысл Ψ и единицы в файлах НЕ заданы
(открытый вопрос, см. §6).

### 1.2. Смысл «замены ОДУ» (операциональные критерии) — из файлов
- *«вместо любых dy/dt, d²y/dt² вглубь вложенности»*;
- *«устраняет ошибки в Piecewise и вложенной дифференциации»*;
- *«Rollback не инициируется; отклонения контролируются до порогов; работает
  автономно в реальном времени без внешнего зависимого дифференцирования»*;
- ноль производных; устойчивость без обвалов; явные параметры.

### 1.3. Ограничение «без производных» — категорическое
Решение автора: производные, относящиеся к дифференциальной системе, **запрещены**.
Следствия:
- объект Ψ(t) (D) **дисквалифицирован** — содержит `|d²Φ/dt²|`;
- непрерывный Курамото `dφ/dt` запрещён → используется **дискретное отображение**
  `φ(k+1)=φ(k)+Δ·[ω+(K/N)Σ_j sin(φ_j−φ_i)]` (оператор d/dt не вычисляется);
- бонус: derivative-free инференс устраняет дефект §3.3 (шумовой Φ″).

## 2. МИССИЯ И ГРАНИЦЫ

### 2.1. Миссия
Дать **альтернативный вычислительный субстрат** для класса задач «извлечь
устойчивую структуру из хаотического фазового поля», работающий там, где
классическое интегрирование ОДУ неудобно/падает, — **без производных, устойчиво,
в реальном времени.**

### 2.2. Чем R43 O1 НЕ является (честные границы, из §4 GLOBAL_CONTEXT)
- НЕ «отмена» ОДУ как класса (категориальная ошибка). «Замена» = победа в нише.
- НЕ статическая дробь (тупик A=B=C).
- НЕ постобработка готового сигнала с Φ″ (объект D дисквалифицирован).

## 3. АРХИТЕКТУРА (три столпа)

```
P1 ЯДРО ДИНАМИКИ (derivative-free, дискретное)
   φ(k+1) = φ(k) + Δ·[ ω + (K/N)·Σ_j sin(φ_j − φ_i) ]      (фазовая связь)
   r·e^{iψ} = (1/N)·Σ_j e^{iφ_j}                            (параметр порядка)
   ρ(k+1)  = ρ(k) + γ·[coh_i − c̄]·ρ(1−ρ/ρ_max)             (плотность по Хеббу)

P2 СОБЫТИЙНЫЙ/СКАЧКОВЫЙ СЛОЙ (ниша замены ОДУ)
   ξ(k) = compound-Poisson скачки; обработка дискретных событий/Piecewise
   без дифференцирования (триггерные пороги вместо производных).

P3 ИЗВЛЕЧЕНИЕ СТРУКТУРЫ (D.I.D.I. F2–F7, подтверждено §3.2)
   coh_ij = cos(φ_i − φ_j);  ансамбли {i,j: coh_ij>θ_coh};  граф G=(A,L)
   θ_local = atan2(Σ sinφ, Σ cosφ)
```

Все три столпа — из зелёных ядер (§3.2) и из конвейера автора (§2.6 GLOBAL_CONTEXT).

## 9. ФОРМАЛЬНЫЙ ОБЪЕКТ R43 O1 («уравнение нового порядка» — честно, с родословной)

R43 O1 — это не одна формула, а **derivative-free динамический объект из трёх
операторов**. Все три не содержат `d/dt` (правило автора соблюдено).

**(I) Уравнение состояния (рекуррента вместо дифференциала):**
```
Ψ_i(k+1) = Ψ_i(k) + Δ·[ ω_i + Σ_j W_ij · sin(Ψ_j(k) − Ψ_i(k)) ]
```
Заменяет `dΨ/dt = f(Ψ)` разностным шагом. Производная не вычисляется — это и есть
смысл «без производных, относящихся к дифференциальной системе».
Родословная: связанные отображения / дискретная динамика / Курамото в дискретном времени.

**(II) Оператор когерентности (считыватель структуры):**
```
C_ij = | ⟨ e^{ i(Ψ_i − Ψ_j) } ⟩_t |        (PLV, фазовое сцепление ∈ [0,1])
```
Родословная: phase-locking value.

**(III) Оператор структуры (спектральный, derivative-free):**
```
ансамбли = спектральная кластеризация(C);  число кластеров K = аргмакс собств. зазора(C)
```
Родословная: спектральная кластеризация (собств. вектора нормированного лапласиана).

**ЧЕСТНО о «новом порядке».** Это НЕ новая ветвь математики (это была ловушка R43).
Каждый кирпич — реальный и заимствованный. «Новый порядок» здесь означает ровно
одно, защитимое: R43 O1 — **derivative-free фазово-рекуррентный субстрат как
АЛЬТЕРНАТИВА системам ОДУ** для ниши «структура из хаоса / событийная динамика».
Вклад — каркас и конвейер, а не новые теоремы. Любая попытка назвать это
«фундаментально новым» без доказательства = анти-паттерн (GLOBAL_CONTEXT §8).

**Что из этого ПОДТВЕРЖДЕНО рабочим (расчётами):** I — Ф1; II+III — Ф2, и
устойчивый вариант III (спектральный) закрыл слабое место Ф3 (`robust.py`:
комбо-экстрим 0.895→0.976, K восстановлен по eigengap). Считыватель «порог +
компоненты связности» признан хрупким и заменён спектральным как стандартный.
