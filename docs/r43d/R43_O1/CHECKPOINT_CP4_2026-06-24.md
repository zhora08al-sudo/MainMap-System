## 2. Считыватель по умолчанию (обновлён в Ф11)
«Корреляция→когеренция»: топ-k относительное ранжирование соседей (корреляционная
ступень убирает общий «пол») → веса рёбер по когеренции → спектральная кластеризация
+ eigengap. Строго лучше PLV+порога; устойчив к общему драйверу.

## 4. Оставшиеся проблемы (полный честный список — см. также чат)
**Фундаментальные (по природе задачи, не баги):**
- F1. Не дешевле/точнее ОДУ-решателя при интегрировании известной системы (Ф4).
- F2. Чисто-топологические сообщества без различия ритма не берутся (Ф10).

**Валидационные (главные научные дыры):**
- V1. Вся валидация — на СИМУЛИРОВАННОЙ динамике (даже Karate/LFR: реальная
  топология, но смоделированные сигналы). Нет НИ ОДНОГО реального измеренного набора.
- V2. Совпадение моделей: генератор и метод — оба Курамото. На не-Курамото данных
  поведение неизвестно (model-match bias).
- V3. Предметная область/единицы Ψ так и не заданы (из исходных файлов).

**Непроверенные интеграции:**
- I1. corr→coh-фикс проверен при N=120; Nyström-масштаб — отдельно с обычным PLV.
  Совместно (масштабируемо И устойчиво к драйверу) — НЕ проверено.
- I2. Гиперпараметр k (число соседей) не исследован на чувствительность.
- I3. eigengap-K не тестирован совместно с драйвером+шумом и при несбалансированных/
  многочисленных сообществах.

**Узость стресса:**
- S1. Проверен один тип конфаунда (один глобальный драйвер). Множественные/частичные
  драйверы, цепочки непрямых связей, mixing-конфаунды — не тестированы.
- S2. Нет совместного экстрима (шум+драйвер+скрытые узлы+масштаб одновременно).

**Концептуальные:**
- C1. Нет теоретических гарантий — всё эмпирически.
- C2. Ограниченная новизна: сборка известных кирпичей (Курамото, PLV, спектральная
  кластеризация, Nyström, kNN) + дисциплина derivative-free + фикс corr→coh.
