## 2. ДВЕ ЧЕСТНЫЕ ГРАНИЦЫ (главное в этой точке)
1. **Конфаунд общего драйвера.** Сильный общий внешний сигнал создаёт ложную
   когерентность между несвязанными сообществами → PLV-аффинность вырождается,
   ARI падает 1.0→~0.5 при κ≥1. Это известная слабость когерентностных мер.
2. **Плотный масштаб.** Точная all-pairs PLV и спектральная кластеризация — O(N²)
   по времени и памяти. Практический потолок ~ тысячи узлов; 10⁴ плотно (≈10⁸
   элементов) нецелесообразно.

## 3. ЧТО ПОДТВЕРДИЛОСЬ СИЛЬНЫМ
- Самоопределение числа кластеров (eigengap) — точно и под шумом.
- Устойчивость к потере наблюдаемых узлов (30% скрыто → ARI 1.0).
- Качество (ARI=1.0) сохраняется до N=2000 при σ_obs=0.2.

## 4. ВОСПРОИЗВЕДЕНИЕ
```
python3 docs/r43d/R43_O1/r43d_o1/harden.py
```
Ожидаемое: T6.1 6/6 PASS; T6.2 ARI=1.0 PASS; T6.3 деградация при κ≥1; T6.4 рост O(N²).

## 5. ПЛАН ПОСЛЕ CP-2 (Ф7 — известные решения обоих пределов)
1. **Масштаб 10⁴:** уйти от плотной O(N²) — landmark/Nyström-приближение
   коэффициентов когерентности + разрежённые/приближённые собственные вектора.
2. **Конфаунд драйвера:** удалить общую компоненту (вычитание глобального
   среднего поля / рангово-1 дефляция) перед когерентностью; проверить
   восстановление ARI при κ≥1.
