## 1. ЧТО ТАКОЕ R43 O1 (одним абзацем, честно)
R43 O1 — **derivative-free фазово-рекуррентный метод открытия структуры связанной
системы из зашумлённых наблюдений**. Он НЕ заменяет интегрирование известных ОДУ
(там решатель лучше — Ф4). Он замещает **дифференциальный (производный) подход к
выводу структуры из данных**, где тот фундаментально рушится под шумом. Метод
устойчив, масштабируем до 10⁴ узлов, сам определяет число сообществ и переживает
потерю узлов; имеет один документированный жёсткий предел — сильный общий драйвер.

## 3. ЧЕСТНЫЕ ПРЕДЕЛЫ (документированы, не скрыты)
1. **Не дешевле ОДУ-решателя при интегрировании известной системы** (Ф4: solve_ivp
   0.023/164 vs R43 O1 0.047/400). R43 O1 — не про это.
2. **Сильный общий драйвер** создаёт ложную когерентность: ARI 1.0→~0.5 при κ≥1.
   Три derivative-free фикса (удаление моды, рангово-1/2 дефляция) НЕ помогли (Ф7).
   Снятие предела вероятно требует направленных/причинных мер — вне правила
   «derivative-free ненаправленная когерентность».
3. **На σ_obs=0 дифф-метод не хуже** (ничья 1.0/1.0) — преимущество только под шумом
   (но реальные данные всегда шумные).

## 4. ОТВЕТ НА ИСХОДНУЮ ЦЕЛЬ «заменить дифференциальные уравнения»
Честно и точно: **буквальная замена ОДУ — нет** (категориальная ошибка, доказано).
**Но найдена реальная, проверенная, масштабируемая ниша**, где derivative-free
подход замещает дифференциальный: **открытие структуры из шумных данных без
уравнений.** Это и есть защитимый смысл цели из исходных файлов автора
(«вместо dy/dt», «структура из хаоса нестабильных данных»).

## 6. ЭКЗОТИЧЕСКИЕ МЕХАНИЗМЫ / НОВЫЕ ПОДХОДЫ (полный список)
- derivative-free фазовая рекуррента (инвариант «ноль d/dt»);
- SC1 токенайзер-аудит инварианта;
- оператор когерентности PLV как аффинность (инвариант к дрейфу фаз);
- спектральное извлечение + eigengap-самоопределение K;
- **landmark/Nyström-когерентность** для масштаба O(N·m) вместо O(N²);
- разрежённый SBM-генератор через sin-разложение (sparse matvec);
- отброшено (честно): медианный оператор C̄, удаление общей моды, рангово-1/2 дефляция.
