## 1. ОДНОЙ ФРАЗОЙ — ЧТО ЗАФИКСИРОВАНО
R43 O1 — **derivative-free фазово-рекуррентный объект**, который НЕ заменяет
интегрирование известных ОДУ (это проиграно честно, Ф4), но **РЕШАЮЩЕ заменяет
дифференциальный подход в открытии структуры связанной системы из ЗАШУМЛЁННЫХ
наблюдений** (Ф5D): там, где производный метод рушится от шума, derivative-free
держит идеальный результат.

## 3. ФОРМАЛЬНЫЙ ОБЪЕКТ (три оператора, ни одного d/dt)

**(I) Уравнение состояния — рекуррента вместо дифференциала:**
```
Ψ_i(k+1) = Ψ_i(k) + Δ·[ ω_i + Σ_j W_ij · sin(Ψ_j(k) − Ψ_i(k)) ]
```
**(II) Оператор когерентности — считыватель сцепления:**
```
C_ij = | ⟨ e^{ i(Ψ_i − Ψ_j) } ⟩_t |        (PLV ∈ [0,1])
```
**(III) Оператор структуры — спектральный:**
```
ансамбли = спектральная кластеризация(C);   K = аргмакс собственного зазора(C)
```

## 4. ЭКЗОТИЧЕСКИЕ МЕХАНИЗМЫ И НОВЫЕ ПОДХОДЫ (детально)

### 4.1. Derivative-free фазовая рекуррента (вместо d/dt)
**Суть:** эволюция задана разностным шагом-отображением, а не интегрированием
производных. Оператор `d/dt` не вычисляется НИГДЕ в рантайме.
**Зачем (нетривиально):** это снимает главный дефект, доказанный в проекте —
вторая производная зашумлённого сигнала усиливает 5% шума в **×1220** раз
(`verification/verify_psi_t.py`). Derivative-free обходит эту катастрофу по построению.
**Родословная (честно):** связанные отображения / Курамото в дискретном времени.
Новизна — не математика, а **дисциплина «ноль производных» как жёсткий инвариант**.

### 4.2. SC1 — статический аудит «derivative-free» через токенайзер
**Суть:** автоматическая проверка, что в вычислительном коде нет операторов
производной. Реализована через `tokenize`: из исходника убираются комментарии и
строковые литералы, затем ищутся запрещённые токены (`np.gradient`, `np.diff`,
`gradient`, `derivative`, `finite_difference`).
**Зачем (экзотика):** наивный строковый скан давал ложные срабатывания (ловил
слово «derivative» в комментарии и `np.diff` на собственных значениях). Токенайзер-
аудит — это **механизм самоконтроля инварианта**, а не просто тест. (Урок зафиксирован:
ранний скан соврал, аудит ужесточён — `r43d_o1/robust.py::check_derivative_free`.)

### 4.3. Оператор когерентности как аффинность (PLV-readout)
**Суть:** структура считывается не из значений сигнала, а из **устойчивости
фазовых РАЗНОСТЕЙ** `cos(Ψ_i−Ψ_j)` во времени (PLV). Это превращает «хаос» в
матрицу сцепления.
**Экзотика:** считыватель инвариантен к абсолютным фазам и к их дрейфу — берёт
только взаимную согласованность. Поэтому он переживает шум и скачки, на которых
гибнут амплитудные/производные считыватели.

### 4.4. Спектральное извлечение + eigengap-самоопределение K
**Суть:** ансамбли извлекаются собственными векторами нормированного лапласиана
матрицы когерентности; число кластеров K определяется по **зазору спектра** —
без знания M заранее.
**Зачем (новый подход в рамках проекта):** заменил хрупкий считыватель «порог +
компоненты связности» (D.I.D.I. F4/F7), который от ОДНОГО ложного ребра под шумом
склеивал сообщества. Эффект измерен: комбо-экстрим **0.895 → 0.976**, и eigengap
**сам нашёл K=6**. (`r43d_o1/robust.py`.)

### 4.5. ⭐ ГЛАВНЫЙ НОВЫЙ ПОДХОД — derivative-free открытие структуры из шума
**Суть:** восстановить структуру связанной системы из **зашумлённых наблюдаемых
сигналов БЕЗ уравнений**. Два пути считывания аффинности, дальше — одинаковая
спектральная кластеризация:
- R43 O1: аффинность = PLV (derivative-free);
- дифференциальный (конкурент): аффинность = |C| из ridge-регрессии Курамото на
  конечно-разностную `dφ/dt` (нужна производная сигнала).
**Почему это «экзотика», а не банальность:** обычный системный анализ выводит связи
через производные. Мы доказали, что это фундаментально хрупко: на чистых данных
дифф-метод идеален (ARI=1.00), но при **любом** шуме (σ≥0.05) обваливается в **≈0**,
тогда как derivative-free держит **ARI=1.00 до σ=0.8**. То есть это и есть честный,
операциональный смысл «заменить дифференциальное» из исходных файлов автора:
**derivative-free там, где производные не работают.** (`r43d_o1/discover.py`.)

### 4.6. Отброшенный механизм (фиксируем честно)
**Многооконная медианная когерентность C̄** (медиана PLV по окнам) — пробовали как
робастный считыватель: дала **0.792** на комбо-экстриме (хуже спектрального 0.976) —
**ОТБРОШЕНА**. Зафиксировано, чтобы не возвращаться. (`r43d_o1/robust.py`, R1.)

## 5. ГРАНИЦЫ И ЧЕСТНЫЕ ОГОВОРКИ CP-1
- **Ниша Ф5D пока на «чистой» синтетике:** чёткие сообщества + свой ритм у каждого,
  прямые связи. НЕ проверено: масштаб 10⁴, непрямые/частичные связи, скрытые узлы,
  конфаунды PLV (общий драйвер → ложная когерентность). Это Ф6.
- **На σ=0 дифф-метод не хуже** (ничья 1.00/1.00). Преимущество R43 O1 — только при
  шуме. Но реальные данные всегда шумные, поэтому ниша реальна.
- **Ф4 остаётся минусом:** как решатель известных ОДУ R43 O1 не нужен. Не возвращаемся.
- Все «новые подходы» — честная сборка реальных кирпичей (Курамото, PLV, спектральная
  кластеризация, ridge). Новизна = каркас, дисциплина и найденная ниша, не теоремы.
