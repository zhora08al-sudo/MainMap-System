# R43 O1 — МЕТОД (паспорт, итоговое оформление)

> Честный «паспорт» метода по итогам Ф1–Ф10. Что он делает, как, что доказано
> числами, где его границы. Без завышенных заявлений. Источник правды —
> `../GLOBAL_CONTEXT.md`; пошаговая история — `STRATEGY.md`; снимки — `CHECKPOINT_CP*`.

## 1. Назначение (одно предложение)
R43 O1 — **derivative-free метод обнаружения ритм-когерентных сообществ связанной
системы по зашумлённым наблюдаемым фазовым сигналам**, без знания уравнений и без
вычисления производных.

## 2. Чем он НЕ является (честно)
- НЕ замена интегрирования ОДУ: решатель (`scipy.solve_ivp`) интегрирует известную
  систему точнее и дешевле (Ф4). R43 O1 — про другое.
- НЕ детектор чисто-топологических сообществ: если у групп нет различия ритма,
  метод их не видит (Ф10, ARI≤0.13).
- НЕ устойчив к сильному общему драйверу (Ф7, предел при κ≥1).

## 3. Где он реально полезен (доказанная ниша)
Восстановление структуры из **зашумлённых наблюдений без уравнений**, где
производный (дифференциальный) подход рушится: derivative-free PLV держит точность
под шумом, дифф-метод обваливается (Ф5D, Ф8, Ф9).

## 4. Алгоритм (три derivative-free оператора)
```
(I)  Состояние:    Ψ_i(k+1) = Ψ_i(k) + Δ·[ ω_i + Σ_j W_ij sin(Ψ_j−Ψ_i) ]   (рекуррента, нет d/dt)
(II) Когерентность: C_ij = |⟨ e^{i(Ψ_i−Ψ_j)} ⟩_t|                          (PLV)
(III)Структура:    спектральная кластеризация(C); число кластеров K = eigengap(C)
```
Масштаб: при больших N — landmark/Nyström-аппроксимация C (O(N·m) вместо O(N²)).

## 6. Точная область применимости и пределы
**Работает, когда:** сообщества отличаются ритмом (частотой); наблюдения зашумлены;
уравнения неизвестны; число сообществ неизвестно (берётся по eigengap); часть узлов
скрыта; N до ~10⁴ (Nyström).
**Не работает, когда:** нужно интегрировать известную ОДУ (Ф4); сообщества чисто
топологические без различия ритма (Ф10); присутствует сильный общий драйвер (Ф7).

## 7. Воспроизведение
```
cd docs/r43d/R43_O1/r43d_o1
python3 discover.py      # ниша: структура из шума vs дифф-метод
python3 phase8_real.py   # реальные топологии (Karate, LFR)
python3 critique.py      # PLV необходима (vs корреляция)
python3 harden.py        # неизв.K / скрытые узлы / драйвер / масштаб
python3 advanced.py      # Nyström-масштаб 10⁴
python3 topo_scope.py    # граница: ритм vs чистая топология
python3 benchmark.py     # честный минус против solve_ivp
python3 core.py          # ядро + r(K)
```

## 8. Связь с исходной целью автора
Буквальная «замена дифференциальных уравнений» — невозможна (категориальная ошибка,
доказано). Но найдена и проверена защитимая интерпретация цели: **derivative-free
там, где дифференциальный/производный подход не работает** — обнаружение ритм-
когерентной структуры из зашумлённых данных. Это честный, рабочий итог R43 O1.

## 9. Возможное развитие (требует ввода/решения автора)
- применение к реальным измеренным данным (нужен датасет + смысл узла/Ψ);
- снятие предела общего драйвера направленными/причинными мерами (вне правила
  «derivative-free ненаправленная когерентность» — требует пересмотра правила).
