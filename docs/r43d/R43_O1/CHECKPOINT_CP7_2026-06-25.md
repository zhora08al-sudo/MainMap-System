## 4. ⭐ ЭКЗОТИЧЕСКАЯ МАСШТАБИРУЕМАЯ ИДЕЯ (зафиксировать для будущего)

**Название:** Иерархия «корреляция → когеренция» (corr→coh hierarchy).
**Артефакт:** `r43d_o1/phase16_hier.py::hier_corr_coh`.

**Суть и ПОЧЕМУ масштабируется (ключевой инсайт):**
- Комплексная когерентность (PLV) = `|⟨e^{iφ_i}, e^{iφ_j}⟩|` — НЕ амортизируется ANN
  (модуль комплексного скалярного произведения не метрика).
- НО корреляция считается на РЕАЛЬНЫХ сигналах `cos(φ)` → это косинусная близость →
  **ANN (KDTree/HNSW) применим** → top-k соседи за O(N·log N), а не O(N²).
- Ранг корреляции по строке ИНВАРИАНТЕН к добавлению общего «пола» (драйвера) →
  отбор кандидатов устойчив к общему драйверу.

**Алгоритм (двухуровневый, derivative-free):**
```
L1 КОРРЕЛЯЦИЯ (масштаб + drive-robust):  cosine-ANN по cos(φ) → top-k кандидаты
L2 КОГЕРЕНЦИЯ (точность):                PLV ТОЛЬКО на рёбрах-кандидатах → разрежённый граф
   → спектральная кластеризация
```

**Доказано (Ф16):** N=10⁴ под драйвером κ=1.5 → ARI=0.993; = полному O(N²) corr→coh,
но масштабируется. κ=0 ≈ κ=1.5 (устойчивость полная).

**Где переиспользовать в будущем:** любая задача «выделить группы из большого поля
зашумлённых сигналов под общим драйвером» — нейросети активаций, сенсорные сети,
энергосети, нейронные ритмы. Принцип «дешёвый масштабируемый отбор (корреляция/ANN)
→ дорогой точный критерий только на кандидатах (когеренция)» — общий и переносимый.
